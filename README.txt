Landing page lista para subir a hosting.

Archivos incluidos:
- index.html
- styles.css
- script.js

Qué ya incluye:
- Sitio bilingüe EN / ES con botón de intercambio.
- Modo dark / light.
- Animaciones en scroll.
- Efecto interactivo en hero.
- Contadores animados.
- Formulario visual de leads.

Importante:
- El formulario actualmente es visual y muestra mensaje de éxito local.
- Para recibir leads reales, conecta el formulario a Formspree, FormSubmit, tu CRM, o un endpoint PHP.
- Todas las imágenes están llamadas por URL externa, así que no necesitas subir assets pesados.

Cómo subir:
1. Descomprime el ZIP.
2. Sube todo el contenido de la carpeta a public_html o a la carpeta de tu dominio.
3. Abre index.html en tu hosting.

Si quieres después, se puede adaptar para:
- envío real por correo
- envío a WhatsApp
- integración con CRM
- formulario en PHP
- conexión con Google Sheets
